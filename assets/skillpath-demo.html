About the project

SkillPath is a full-stack web app I built to solve a simple problem: beginners know what they want to learn but not where to start or how to stay on track.

Version 1 generated basic roadmaps. Version 2 added proper security, a smarter roadmap engine, AI generation, live dashboard updates, streaks, notes and automated tests.
